## 💻 Tema do Projeto: O Ecossistema Cyber-Agro

O **AgroFuturo 2026** é uma Landing Page de alto padrão projetada para consolidar o papel do Brasil como o principal polo de tecnologia agrícola sustentável do mundo. 

Diferente de interfaces tradicionais do agronegócio, este projeto utiliza a vertente visual **Cyber-Agro Premium**. Isso significa aplicar conceitos modernos da engenharia de software front-end para criar uma atmosfera imersiva de tecnologia:

* **Glassmorphism (Efeito Vidro):** Utiliza desfoque de fundo avançado (`backdrop-filter`) combinados com transparências sutis, dando a impressão de painéis holográficos flutuantes sobre o solo.
* **Neon Highlights:** Pontos estratégicos brilhantes utilizando as cores Azul Celeste e Verde Tech para guiar os olhos do usuário diretamente para os pontos de conversão.
* **Contraste Otimizado:** Alinhamento rígido com as diretrizes da WCAG (diretrizes de acessibilidade web), garantindo que textos em cinza e branco tenham leitura perfeita sobre o fundo escuro industrial.

---

## 🎯 Objetivo Estratégico da Página

A plataforma cumpre duas missões críticas de mercado em uma única tela:
1. **Autoridade de Conteúdo:** Funciona como um portal rico de informações que detalha as descobertas de Mariangela Hungria e Luciana Gorab, elevando o nível de percepção da marca.
2. **Captação de Leads (Inbound Marketing):** Atua como uma ferramenta ativa de conversão através de um formulário lateral de alta performance que se mantém fixo enquanto o usuário rola o texto.

## 🛠️ Arquitetura Técnico e Recursos de Engenharia

O projeto foi construído utilizando os pilares modernos do desenvolvimento web para garantir velocidade e manutenibilidade:

| Componente | Tecnologia | Propósito Técnico |
| :--- | :--- | :--- |
| **Grid Assimétrico** | CSS Grid & Flexbox | Cria um layout dinâmico onde a coluna de conteúdo ocupa `1fr` (espaço flexível) e a barra de formulário ocupa um tamanho fixo ideal para desktop, colapsando perfeitamente para uma única coluna em celulares. |
| **Accordion Fluido** | Vanilla JavaScript | Calcula o tamanho do conteúdo em tempo real usando `scrollHeight`. Isso impede travamentos visuais e cria uma transição limpa quando o usuário clica para descobrir as vantagens da IA. |
| **Filtro Semântico de Voz** | SpeechSynthesis API | API nativa dos navegadores configurada para clonar o código, limpar tags indesejadas (como botões e caixas de texto) e ler apenas o artigo de forma humana e fluida. |
